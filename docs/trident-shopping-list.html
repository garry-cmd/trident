Case change — GPIO access required

The Flirc Pi 5 case blocks GPIO access, which we need for the alarm relay. Use the Argon NEO 5 instead — aluminum passive cooling with a removable magnetic top that exposes GPIO.

Before you order — verify

1. Does your N2K backbone have a spare T-connector? If yes, skip that purchase ($25 saved). 2. Measure actual VE.Direct cable runs to each MPPT and to the BMV-712 install location — pick the right lengths. 3. Confirm the Peplink part number includes "-W" for WiFi AP capability. 4. The Cerbo GX MK2 does NOT include a DIN rail adapter — buy separately (~$12) if panel-mounting. 5. Check if the Cerbo includes an N2K drop cable — some bundles do, some don't.
